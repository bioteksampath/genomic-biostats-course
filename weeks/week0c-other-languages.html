1 R vs Python — the honest answer

Task Reach for
Mixed models, quantitative genetics, GWAS/GS R (sommer, BGLR, rrBLUP — unmatched)
Publication figures, interactive apps R (ggplot2, Shiny)
Deep learning, large-scale ML engineering Python (scikit-learn, PyTorch)
Workflow orchestration on clusters Python-adjacent (Snakemake, Nextflow)
Sequence wrangling at scale Bash + compiled tools (samtools, bcftools)

In a biostatistics role you will live in R and read Python. This course mirrors that.

2 Python in 15 lines (Week 4 preview)

import pandas as pd
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import cross_val_score

X = pd.read_csv("data/wheat_markers.csv")     # lines x SNPs
y = pd.read_csv("data/wheat_pheno.csv")["yield"]

rf = RandomForestRegressor(n_estimators=500, n_jobs=-1, random_state=1)
print(cross_val_score(rf, X, y, cv=5, scoring="r2").mean())

Same logic as R’s ranger — different dialect.

## R vs Python — the honest answer

| Task | Reach for |
|---|---|
| Mixed models, quantitative genetics, GWAS/GS | **R** (sommer, BGLR, rrBLUP — unmatched) |
| Publication figures, interactive apps | **R** (ggplot2, Shiny) |
| Deep learning, large-scale ML engineering | **Python** (scikit-learn, PyTorch) |
| Workflow orchestration on clusters | **Python-adjacent** (Snakemake, Nextflow) |
| Sequence wrangling at scale | **Bash + compiled tools** (samtools, bcftools) |

In a biostatistics role you will live in R and *read* Python. This course mirrors that.

## Python in 15 lines (Week 4 preview)

```python
import pandas as pd
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import cross_val_score

X = pd.read_csv("data/wheat_markers.csv")     # lines x SNPs
y = pd.read_csv("data/wheat_pheno.csv")["yield"]

rf = RandomForestRegressor(n_estimators=500, n_jobs=-1, random_state=1)
print(cross_val_score(rf, X, y, cv=5, scoring="r2").mean())
```

Same logic as R's `ranger` — different dialect.
