## The six tidyverse verbs that do 90% of work

```{r}
library(tidyverse)
oats <- agridat::yates.oats   # a real 1930s split-plot oat trial (Yates)
glimpse(oats)

oats |>
  filter(nitro > 0) |>
  mutate(yield_t = yield * 0.0251) |>
  group_by(gen, nitro) |>
  summarise(mean_yield = mean(yield), .groups = "drop") |>
  arrange(desc(mean_yield)) |>
  head()
```

`filter` rows · `select` columns · `mutate` new variables · `group_by`+`summarise` aggregate · `arrange` sort · `left_join` merge (genotype ↔ phenotype tables).
